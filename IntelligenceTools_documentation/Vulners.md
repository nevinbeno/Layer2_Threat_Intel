# $Vulners$: Multi - Source Intelligence
Vulners is like a search engine for vulnerabilities. It aggregates data from:
- NVD
- Vendor advisories (Microsoft, Cisco, Palo Alto, etc.)
- Exploit DB
- Metasploit
- GitHub PoCs
- Blogs
- Forensic reports

### Why we need Vulners: Because it adds real-world context:
- Is there a public exploit available?
- Are there GitHub PoCs?
- Is it weaponized in the wild?
- Is it trending?
- Faster updates than NVD
- Enriched metadata beyond the official CVE

Vulners is not just CVE information. It gives threat intelligence, not only vulnerability info.
