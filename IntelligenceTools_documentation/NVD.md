# $NVD$: Oficial Vulnerability Details Database. 
NVD (National Vulnerability Database) is maintained by the U.S. government.
It provides:
- Official CVE data
- CVSS scores
- Severity (Low/Med/High/Critical)
- Detailed descriptions
- CPE (Common Platform Enumeration)
- Metrics for exploitability & impact

Why we need NVD:
Because it is the gold standard reference. If someone questions our results, NVD is the source nobody can reject.
It gives the most structured, complete, and standardized vulnerability metadata.
